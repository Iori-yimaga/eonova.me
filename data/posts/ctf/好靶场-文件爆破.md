# 文件爆破 — 好靶场 Hacker Game

## 题目信息

| 项目     | 内容                                        |
| -------- | ------------------------------------------- |
| 平台     | 好靶场                                      |
| 分类     | WEB安全                                     |
| 题目     | 文件爆破专项练习                            |
| 目标     | `http://p3w7z5l.haobachang2.loveli.com.cn:8888/` |
| Flag     | `flag{02d87cb974ac451c9c3ef4542e14bc03}`    |

## 摘要

通过目录爆破（fuzzing）发现隐藏的 `tz.php` 探针页面，获取 flag。关键点在于需要使用**足够大的字典**——普通小字典无法覆盖到 `tz.php` 这种非常规文件名。

## 解题过程

### Step 1: 信息收集

访问目标页面，获取基本信息：

```bash
curl -sI "http://p3w7z5l.haobachang2.loveli.com.cn:8888/"
```

**关键信息：**
- **Server**: Apache/2.4.10 (Debian)
- **X-Powered-By**: PHP/5.4.45
- 主页面为 `index.php`，标题为 "Hacker Game 文件爆破"
- 提示语：*"文件爆破是渗透测试中常用的技巧，可以帮助我们发现隐藏的敏感敏感文件和目录"*
- 帮助按钮提示：*"可以找找有没有可疑的文件"*

页面上定义了扫描器相关的 CSS 类（`dir-input`、`hack-btn`、`scan-output`、`list-files`、`progress-bar`），但未在 HTML 中使用，暗示需要使用外部工具进行爆破。

### Step 2: 尝试常见路径

首先手动探测常见路径，均返回 404：

```bash
# 常见敏感文件
robots.txt, .git/HEAD, .env, .htaccess, .htpasswd
backup.zip, www.zip, flag.txt, flag.php
admin/, upload/, shell.php, config.php ...
```

仅发现 Apache 默认的 403 页面：
- `/.htpasswd` → 403
- `/.htaccess` → 403
- `/server-status` → 403
- `/icons/` → 403

> 使用 Python 并行脚本扫描了上千个常见路径，均无有效结果。说明目标文件名非常规。

### Step 3: 安装 ffuf 并使用大字典爆破

安装专业爆破工具 `ffuf`，下载 SecLists 的 `raft-medium-files.txt` 字典（17129 条）：

```bash
# 安装 ffuf
brew install ffuf

# 下载字典
curl -sL "https://raw.githubusercontent.com/danielmiessler/SecLists/master/Discovery/Web-Content/raft-medium-files.txt" \
  -o /tmp/raft-medium-files.txt

# 执行爆破
ffuf -u "http://p3w7z5l.haobachang2.loveli.com.cn:8888/FUZZ" \
     -w /tmp/raft-medium-files.txt \
     -mc all -fc 404 -t 50 -timeout 3
```

### Step 4: 发现隐藏页面

在字典扫描接近尾声时（约第 16779 条），发现了隐藏文件：

```
tz.php    [Status: 200, Size: 1058, Words: 52, Lines: 7]
```

访问该页面：

```bash
curl -s "http://p3w7z5l.haobachang2.loveli.com.cn:8888/tz.php"
```

返回内容：

```html
<h1>🎯 你竟然找到了隐藏的探针页面！</h1>
<div class="flag">flag{02d87cb974ac451c9c3ef4542e14bc03}</div>
<div>flag保存在 /tmp/flag.txt</div>
```

## 解题脚本

```bash
#!/bin/bash
# 好靶场 - 文件爆破 解题脚本
TARGET="http://p3w7z5l.haobachang2.loveli.com.cn:8888"

# 安装工具
which ffuf || brew install ffuf

# 下载字典
curl -sL "https://raw.githubusercontent.com/danielmiessler/SecLists/master/Discovery/Web-Content/raft-medium-files.txt" \
  -o /tmp/raft-medium-files.txt

# 爆破
ffuf -u "$TARGET/FUZZ" \
     -w /tmp/raft-medium-files.txt \
     -mc all -fc 404 -t 50 -timeout 3

# 获取 flag
curl -s "$TARGET/tz.php" | grep -oP 'flag\{[^}]+\}'
```

## 工具与环境

| 工具/资源                    | 用途               |
| ---------------------------- | ------------------ |
| `curl`                       | HTTP 请求与探测    |
| `ffuf` v2.1.0                | 高速目录爆破       |
| `raft-medium-files.txt`      | 17129 条文件名字典 |
| Python `concurrent.futures`  | 并行扫描（备选）   |

## 关键收获

1. **字典大小很重要** — `tz.php` 是非常规文件名，小字典（如 `common.txt` 的 4750 条）无法覆盖，需要 `raft-medium`（17129 条）级别的字典
2. **ffuf 比 curl 脚本快得多** — ffuf 单线程即可达到 1000+ req/s，17000 条字典仅需约 17 秒
3. **信息收集先行** — 通过响应头（`Server: Apache/2.4.10`, `X-Powered-By: PHP/5.4.45`）确认技术栈，排除不相关的路径
4. **注意 CSS 类名暗示** — 页面定义了扫描器相关的 CSS 类但未使用，暗示"该用工具扫描了"
